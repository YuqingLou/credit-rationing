# 高级微观经济学课程论文：大数据如何缓解信贷逆向选择与创业抑制

## 论文实证部分数据

### 微观数据：2019年中国家庭金融调查（CHFS) 
数据源：https://chfser.swufe.edu.cn/data/

### 宏观数据：2019年《北京大学数字普惠金融指数》finance2019.xlsx 
数据源：郭峰,王靖一,王芳,孔涛,张勋,程志云.测度中国数字普惠金融发展:指数编制与空间特征[J].经济学(季刊),2020,19(04):1401-1418.

通过匹配家庭所在省份构建了一个包含33835个家庭户主的截面数据集combined.dta
